## Criterio di separazione
- I concetti del linguaggio sono in `02_GUIDA_INTRODUTTIVA.md`.
- Lo stack tecnico del compilatore e del monitor e in `03_IMPLEMENTAZIONE.md`.
- Gli esempi sono separati per dominio e includono le rispettive soluzioni quando presenti.
- `04_DOWNLOADS.md` contiene solo i repository ufficiali indicati dal sito.
